### Gold collateral return, auction surplus, ₹5,000/day

**What is it?**
Once a gold loan is fully repaid, the jewellery is **not the NBFC’s asset**. It must go back **the same day**, and in any case within **seven working days**. If the loan instead goes to auction, the borrower still owns the **surplus** after dues. Keeping that surplus is how KLM Axiva picked up a **₹2.70 lakh** penalty on **24 Sep 2026**.

**The Technical Details**
**Source:** *Reserve Bank of India (Non-Banking Financial Companies – Responsible Business Conduct) Directions, 2025* (updated as on **1 Jul 2026**), **Chapter III, Section G**, paras 42–75. `RBI/DOR/2025-26/362`, `DOR.MCS.REC.No.281/01-01-039/2025-26` (28 Nov 2025). PDF: [362MD…5808.PDF](https://rbidocs.rbi.org.in/rdocs/notification/PDFs/362MD26CA543937BA439A97E1BCFC08CF5808.PDF). Page: [id=12942](https://rbi.org.in/Scripts/BS_ViewMasDirections.aspx?id=12942). Prudential overlay (LTV, valuation, 1 kg / 50 g caps) remains Credit Facilities Chapter IV, paras 32–50 — **already taught 7 Oct; do not re-open**.

**Applies to:** All layers of NBFC-ICC / NBFC-D / NBFC-MFI / HFC etc. that have **customer interface** and actually do this product (RBC paras 3–5). MFL = **ML**. Muthoot Finance = **UL peer** — same Chapter III-G product rules; different SBR overlay.

**Why it matters**
LTV tells you whether you may **lend**. Section G tells you whether you may **keep the gold or the cash**. Supervisors read auction surplus as **other income that does not belong to you**. A 7-working-day miss on return is not an ops inconvenience — it is **₹5,000 per day**, statutory, on top of any other law (para 70).

**Key Numbers / Thresholds**

| Rule | Number | Source |
|------|--------|--------|
| Return pledged gold / silver after full repayment | **Same day**, max **7 working days** | Para 58 |
| Delay compensation (if attributable to the NBFC) | **₹5,000 per day** after day 7 | Para 69 |
| Assay certificate | Duplicate on letterhead: carat, gross wt, net wt, deductions, defects, **image**, value | Para 50 |
| Borrower present at assay | **Mandatory** at sanction | Para 46 |
| Who may handle collateral | **Only NBFC employees, only in branches** | Paras 53–54 |
| Storage | Branch with **employees + safe-deposit vault** fit for gold/silver | Para 54 |
| Transport between branches | Only for **auction (para 64)** or branch shift/closure / exceptional policy reasons | Para 55 |
| Auction notice | Adequate notice + acknowledgement on file; if untraceable, **public notice + 1 month** | Para 60 |
| Public advertisement | **Two newspapers** — one regional, one national daily | Para 61 |
| Who auctions | Trained **employee** or **empanelled auctioneer**; related parties **cannot bid** | Paras 62, 65 |
| First auction location | **Physical, same district** as lending branch | Para 64 |
| Failed first auction | Adjoining district **or** online | Para 64 |
| Reserve price | **≥ 90%** of current value; after **two failed** auctions, **≥ 85%** | Para 63 |
| Auction surplus refund | **7 working days** from receipt of full auction proceeds | Para 66 |

**Recent Changes**
Previously: gold-auction surplus and delayed-return were FPC / Fair Practices folklore, enforced case-by-case. Now (RBC 2025, gold rewrite **live 1 Apr 2026** — Annex II of RBC **deleted** w.e.f. that date, footnote 3; conduct moved into Section G): the **7-day clocks and the ₹5,000/day** are numbered paragraphs. **KLM Axiva, PR 1181, 24 Sep 2026** is the first post-rewrite public fine on **surplus not returned**. The 16 Sep SC repossession overlay is a **second** conduct layer on recovery — still **no** RBI circular, still live.

**Muthoot Fincorp Context**
- Core book is **branch gold**. Paras 53–54 are not optional: jewellery is handled **in branch, by employees, in a vault**. DSAs do not take gold home.
- Auction surplus is **not “other income”**. Map the GL: auction proceeds → dues → **payable to borrower** within 7 working days. KLM Axiva is the template for what DoS looks at.
- ₹5,000/day is a **P&L and grievance** number. A 10-working-day return miss on one loan is ₹15,000 statutory (days 8–10) before any Ombudsman add-on.
- First auction **must** be physical in the **same district**. Online / adjoining-district is only after a **failed** first auction. Do not “centralise” auctions to a metro hall on attempt one.
- Unclaimed gold > 2 years is a **Board / CSC** half-yearly item (para 72), not a branch leftover.
- SNFA (live 1 Oct) still does **not** apply to pledged jewellery. Do not mix SNFA into auction surplus.
- FP&A: for the 14 Nov pack, auction-surplus payable and delayed-return compensation are **conduct contingencies**, not yield. Keep them off “other income”. Muthoot Finance (UL) is a separate issuer with the same Section G product rules.

### Microfinance — recovery place, hours, no prepayment charge

**What is it?**
MFI conduct is **Chapter III-H** of the **same RBC MD**, not Credit Facilities Chapter V (that was last Wednesday’s FOIR 50%). Today is how you **collect**, not how you **underwrite**.

**The Technical Details**
**Source:** RBC Directions 2025, **Chapter III, Section H**, paras 76–91+. Activity-based: any NBFC doing microfinance loans, not only NBFC-MFIs.

**Key Numbers / Thresholds**

| Rule | Number | Source |
|------|--------|--------|
| FPC for microfinance | Board-approved; **every branch + website**; language the borrower understands | Para 76 |
| Loan card | ID, simplified pricing factsheet, T&Cs, repayment acknowledgements, **nodal grievance name + number** | Para 78 |
| Prepayment charge on microfinance | **Nil** | Para 81 |
| Delayed-payment charge | On the **overdue amount only**, not the whole loan | Para 81 |
| Rate display | Min / max / **average** interest, offices + literature + website + supervisory return | Para 82 |
| Rate change | Informed in advance; **prospective only** | Para 83 |
| Borrower training | **Free** | Para 88 |
| Recovery place | Mutually agreed **designated / central** place | Para 90 |
| Home / workplace recovery | Only if borrower misses the designated place on **two or more successive** occasions | Para 90 |
| MFI call window (harsh-method list) | **Not before 9:00 a.m., not after 6:00 p.m.** | Para 91(2) |
| Harsh methods (non-exhaustive) | Threats, abusive language, harassing relatives / friends / co-workers, publishing names | Para 91 |

**Contrast with the 1 Jan 2027 recovery-agent stack (do not re-teach Thursday’s class):** general recovery-agent hours are **08:00–19:00**. MFI para 91 is **tighter: 09:00–18:00**. If a group entity runs both gold recovery and an MFI book, the **MFI clock wins on MFI loans**. SC repossession overlay (16 Sep) sits on top of both.

**Muthoot Fincorp Context**
Gold recovery is **auction + surplus**, not doorstep. MFI recovery is **centre / designated place first**. Do not let a gold-branch collection culture leak onto an MFI card. Prepayment charges that are fine on a gold bullet after cooling-off are **illegal on a microfinance loan** (para 81). For FP&A: MFI fee income cannot include foreclosure fees; gold can, after the 7-day cooling-off on digital / as disclosed in KFS.
