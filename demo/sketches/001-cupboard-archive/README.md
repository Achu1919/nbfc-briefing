## Variant: Cupboard archive

### Design stance
The library is a shelf of days, not a homepage. You pick a date, then a document.

### Key choices
- Layout: three columns — dates / files / reader
- Typography: Source Serif 4 for reading, IBM Plex Sans for the shelf
- Color: paper and olive, no product-blue
- Interaction: click a day, open a file; missing jobs stay visible as holes

### Trade-offs
- Strong at: showing how filing actually works, including failures
- Weak at: Saturday-morning pleasure. It is a cupboard.

### Best for
Checking whether the *idea* of a dated archive is useful before dressing it.
