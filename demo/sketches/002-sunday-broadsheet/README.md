## Variant: Sunday broadsheet

### Design stance
The archive wears a newspaper. Front page first; Markets and Rules are inside pages.

### Key choices
- Layout: masthead, one lead, column + rail
- Typography: Fraunces display, Newsreader body, IBM Plex Mono labels
- Color: warm newsprint, a single red rule
- Interaction: four sections — Front, Markets, Rules, How this works

### Trade-offs
- Strong at: making you want to open it
- Weak at: browsing last month. The cupboard does that better.

### Best for
The daily reading ritual — if this is the cover you would actually sit with.
